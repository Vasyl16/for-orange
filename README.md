# FreshCart (shop-app)

## Як це працює

Магазин на **React** + **Vite**.

Товари завантажуються з інтернету функцією **`fetchProducts`** (файл `services/api.js`).

Список товарів тримається в стані: **`useState`**.

Кошик — це масив: у кожному рядку є **товар** і **кількість**.

Щоб додати, прибрати або змінити кількість, використовуються функції в **`App.jsx`**.

Сторінки перемикаються через **`react-router-dom`**.

Папка **`pages/`** — екрани.

Папка **`components/`** — кошик і картки товарів.

## Запуск

```bash
npm install
npm run dev
```
