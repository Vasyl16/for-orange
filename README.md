# FreshCart (shop-app)

## Як це працює

Магазин на **React** + **Vite**.

Товари завантажуються з інтернету функцією **`fetchProducts`** (файл `services/api.js`).

Список товарів тримається в стані: **`useState`**.

Кошик — це масив: у кожному рядку є **товар** і **кількість**.

Щоб додати, прибрати або змінити кількість, використовуються функції в **`App.jsx`**.

Сторінки перемикаються через **`react-router-dom`**.

Папка **`pages/`** — екрани.

Папка **`components/`** — кошик і картки товарів.

## Запуск

```bash
npm install
npm run dev
```

## GitHub Pages (чому 404 на CSS/JS)

Сайт лежить за адресою виду `https://user.github.io/назва-репо/`, а в `index.html` були шляхи **від кореня домену** (`/assets/...`). Браузер шукав файли на `github.io/assets/`, а не в папці репозиторію — тому **404**.

У кореневому `index.html` потрібні **відносні** шляхи: `./assets/...`. Після кожного `npm run build` імена файлів у `dist/assets/` змінюються — копіюй оновлений `index.html` з `dist/`.

У `vite.config.js` додай `base: './'` (або `base: '/назва-репо/'`), щоб збірка сама підставляла правильні шляхи. Для роутера на підшляху потрібен `basename` у `BrowserRouter` (див. документацію React Router).

Помилка з **chrome-extension://…** йде з розширення Chrome, не з проєкту.
